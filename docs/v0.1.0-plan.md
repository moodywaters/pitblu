## Minimal scaffold

- `pyproject.toml` with an exact Bleak runtime dependency and exact development-tool versions
- `src/pitboss_admin/protocol.py` for pure payload decoding
- `src/pitboss_admin/ble_spike.py` for the short-lived hardware proof
- `tests/` for hardware-independent protocol, authentication and privacy tests
- GitHub Actions and Dependabot configuration
- required top-level and `docs/` publication-readiness structure

## Smallest physical proof sequence

1. Prepare an isolated Python 3.13 virtual environment on the target Pi.
2. Install the project and run hardware-independent checks.
3. Power the V202, close the official application and insert at least one probe.
4. Run the proof, which discovers only the exact advertised name for up to 20 seconds.
5. Connect, verify the V202 temperature service and complete zero-challenge loopback authentication.
6. Read the temperature unit, four probe characteristics and standard battery characteristic.
7. Confirm at least one decoded Celsius temperature matches the display within 1 degree Celsius and
   that the sanitised output contains no Bluetooth address.
8. Record the redacted evidence in `docs/physical-acceptance.md` and only then complete v0.1.0.
