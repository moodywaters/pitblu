# pitblu-web

Reserved for the future web frontend. No application is implemented or released
here yet. It will consume pitblu-core's REST, SSE and MQTT interfaces and remain
separately buildable and deployable.

Start with the [frontend integration guide](../docs/frontend-integration.md) and
the [candidate status](../docs/release-status.md). Do not move cook sessions,
graphs, history or alarms into the hardware gateway.
