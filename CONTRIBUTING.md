# Contributing

Use Python 3.11 through 3.13, British English in documentation, and small milestone-aligned changes.
Code, tests, documentation and provenance must change together. Run all commands listed in
`README.md` before submitting a change.

Do not add secrets, private Bluetooth addresses, LAN addresses, local configuration, Docker files,
cook-session features or work from a later milestone. Do not copy or substantially adapt external
code without first recording its exact revision, licence and affected component.
